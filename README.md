This code plots points within a square around a circle and uses the ratio between the areas of the shapes to approximate pi.

The unit circle has an area of pi whilst the square around it has an area of 4.
With enough points, you can say that the proportion of points in the circle approaches pi/4.
Multiplying this ration by 4 should, in theory, give an approximate value for pi.
As the number of slices and points increase, the approximation becomes better.
